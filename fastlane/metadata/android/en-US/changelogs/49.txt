Spotify on this phone's Music Assistant now also plays with accounts created since December 2024: when you add Spotify, choose Soloist, Spotify's official engine. It needs your own Soloist API key and, once, picking "Music Assistant Pairing" in the Spotify app, on Wi-Fi. Soloist runs inside proot, in a small Linux system that comes with the server download. In Settings, "Music Assistant log" fetches the log of the server Xonos is connected to.
